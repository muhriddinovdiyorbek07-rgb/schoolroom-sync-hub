# Class Connect Hub

I need a website where there is a registration section, with animated backgrounds and templates. The main thing is that its backend and frontend are separate, and the frontend should be built with CSS, JavaScript, Node.js, and HTML so that it looks high-quality and nice. The site will have both users and admins, and they will connect to a database. During registration, the admin is accepted with a login added to a separate site. The backend should be built with Python and JavaScript. The site should be functional and modern. When users enter, they choose their district, region, and school, and they are assigned to their class. The online site should have user accounts, where they are students, and there should be a separate admin panel. For now, just complete this part.
